# Omole Daniel – Digital Imaging Portfolio

A single-page portfolio of 12 generative 2D and 3D images, drawn live in the browser with Canvas 2D and Three.js.

## Run locally
Open `index.html` in a browser (needs internet for the Three.js and font CDNs).

## Publish with GitHub Pages
1. Push this folder to a GitHub repository.
2. Repo Settings > Pages > Deploy from a branch > `main` / root.
3. Your site appears at `https://<username>.github.io/<repo>/`.

## Edit
Name and email are in the `CFG` line near the top of the script in `index.html`.
